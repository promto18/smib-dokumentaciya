# Репозиторий документированной информации СМИБ — АО «ДемоБанк»

Назначение: централизованное ведение документированной информации СМИБ
в соответствии с п. 7.5 ISO/IEC 27001:2022.

Структура:
- 01-politika/          — политика ИБ верхнего уровня (утверждает первый руководитель)
- 02-chastnye-politiki/ — частные политики (утверждает руководитель по ИБ)
- 03-procedury/         — процедуры и регламенты (владельцы процессов)
- 04-instrukcii/        — инструкции, шаблоны, чек-листы
- 05-zapisi/            — шаблоны записей (доказательная база)

Порядок внесения изменений: все изменения вносятся через отдельную ветку
и запрос на слияние с обязательным рецензентом.
Прямая запись в ветку main запрещена. Утверждённая редакция помечается тегом.
